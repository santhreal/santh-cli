# santh-cli Specification

## Contract

Every binary using this crate implements `SanthCli` and delegates its `main` to
`santh_main::<Tool>()`.

## Global Flags

All tools expose:

- `--config <PATH>` for a Tier A config override.
- `--output <json|sarif|human>`.
- `--log-level <trace|debug|info|warn|error>`.
- `--quiet` / `-q`, which uses error-level logging unless `--log-level` is
  explicitly supplied.
- `--metrics-port <PORT>`, where `PORT` must be in `1..=65535`.

`--help` and `--version` are generated by `clap`.

## Exit Codes

- `0`: successful run with no findings.
- `1`: successful run with findings.
- `2`: user-correctable error.
- `3`: system error.
- `130`: interrupt.

## Config Resolution

`resolve_config` checks the explicit path first, then default paths in order,
then returns `Default::default()` when no file exists.

Missing explicit paths are errors. Missing default paths are ignored.

## Finding Emission

`emit_finding` accepts a `secfinding::Finding` and writes exactly one finding in
the requested format.

JSON mode writes one compact JSON object followed by `\n`.

SARIF mode writes a complete SARIF 2.1.0 document followed by `\n`.

Human mode writes colorized ANSI output with severity, title, target, type,
optional location, detail, and remediation.

## Error Policy

All public fallible operations return typed errors with actionable `Fix:`
messages. Production code does not unwrap, panic, or discard write and parse
errors.
